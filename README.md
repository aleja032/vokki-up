# Vokki Up

Mobile-first, local-first PWA to learn English vocabulary with spaced repetition. The UI is in Spanish.

## Stack

Next.js 16, React 19, TypeScript, Tailwind CSS v4, React Hook Form + Zod, Supabase, Vitest.

## Getting started

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

## Scripts

| Script       | Purpose                 |
| ------------ | ----------------------- |
| `pnpm dev`   | Start the dev server    |
| `pnpm build` | Production build        |
| `pnpm lint`  | Lint `src`              |
| `pnpm test`  | Run the Vitest suite    |
